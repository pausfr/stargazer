## Q1. 프런트엔드 스택(프레임워크/빌드)

u4-web-ui는 단일 정적 번들의 진입점입니다(백엔드 없음, NFR7). 어떤 방식으로 만들까요?

- A. Vanilla TypeScript + Vite (프레임워크 없이, 가장 가벼움 — 화면 2개뿐)
- B. React + Vite (컴포넌트 모델이 익숙하고 상태 관리가 편함, 번들은 약간 큼)
- C. Svelte + Vite (가볍고 반응성 좋음)
- X. Other (please specify)

[Answer]: A. Vanilla TypeScript + Vite

## Q2. 그래프 렌더링 방식 (상세 화면 이중축 그래프)

x=시간, 좌y=달 밝기(0~100%), 우y=구름량(%)을 겹치고 박명 음영/완전한 밤 구간을
표시해야 합니다. 어떻게 그릴까요?

- A. 경량 차트 라이브러리(uPlot 또는 Chart.js) — 이중축·음영 영역 지원, 빠른 구현
- B. SVG 직접 렌더링(라이브러리 없음) — 번들 최소, 박명 음영 커스텀 자유, 구현 품이 큼
- C. D3 — 유연하나 무겁고 학습비용 높음
- X. Other (please specify)

[Answer]: A. 경량 차트 라이브러리 — 구체적으로 Chart.js 4 + chartjs-plugin-annotation 3. 이중축(좌 달 밝기 0~100%, 우 구름량 %)은 Chart.js 코어가 선언적으로 지원하고, 박명 3구간 + 완전한 밤 음영은 annotation 플러그인의 box 타입으로 x구간 반투명 밴드를 얹어 표현한다(캔버스 수동 렌더링 불필요). uPlot보다 번들은 크나 화면 2개 앱에서 수용 가능하고 음영 구현 품이 작다.

- C. 상수로 한 곳 정하되 값은 구현에서 확정(설계에선 "전국 대표 좌표 1개"로만 고정)
- X. Other (please specify)

[Answer]: A. 서울 도심(위도 37.5665, 경도 126.9780). UI가 이 좌표를 U1/U2 호출에 넘긴다. 상수로 한 곳에 고정한다.
