## 외부 의존 목록

이 프로젝트는 백엔드 없는 1인·AI 정적 앱이라 외부 의존이 가볍다. 승인 대기나 타팀 핸드오프는 없다(Q5=A). 외부 경계는 둘뿐:

| 의존 | 종류 | 소유 | 리드타임 | 막는 Bolt | 미끄러질 때(slip) 대응 |
|------|------|------|----------|-----------|------------------------|
| 무료 날씨 API(Open-Meteo류) 선정·무료 한도·예보 지평·운량 필드 확인 | 외부 third-party API | 프로젝트 소유자(직접 선정) | 짧음(수 시간, 공개 API 조사) | Bolt 2 (날씨 연동) | Bolt 1은 날씨 스텁으로 선행 가능하므로 블로킹 아님. 선정이 늦으면 Bolt 2만 지연 |
| 오픈소스 천문 계산 라이브러리 선정 + 전국 대표 좌표 확정 | 외부 라이브러리/데이터 | 프로젝트 소유자(직접 선정) | 짧음 | Bolt 1 (U1 최소) | 대안 라이브러리 복수 존재. 지연 시 Bolt 1 지연이나 위험 낮음 |
| 한국 공휴일 데이터/규칙 | 외부 데이터 | 프로젝트 소유자 | 짧음 | Bolt 3 (U3 전체 달력) | 공개 데이터/규칙 다수. Bolt 1 스켈레톤은 날짜 하나만 쓰므로 블로킹 아님 |

## 메모

- 모든 외부 의존은 공개·무료 범위이며 승인 게이트가 없다. 가장 신경 쓸 항목은 날씨 API이며, Bolt 1에서 스텁으로 선행해 Bolt 2 전까지 선정을 끝내면 블로킹이 생기지 않도록 설계했다.
- 비밀값(API 키)을 클라이언트 번들에 두지 않는다(NFR6). 키가 필요 없는 공개 API 우선, 키 필요 시 Functional Design에서 프록시 여부 결정.
