## P1. 취미 관측자 (주 사용자)

| 항목 | 내용 |
|------|------|
| 이름 | 취미 관측자 (나와 친구들) |
| 역할 | 앱의 유일한 사용자 겸 의사결정자 |
| 목표 | 시간 낼 수 있는 주말·연휴 중 별 보기 좋은 밤을 빠르게 가늠한다 |
| 통증 | 달 위상·구름·박명 정보가 흩어져 있어 매번 수동으로 조합해야 함 |
| 기술 이해도 | 중~상 — 달 위상·박명 시각 등 구체 수치를 직접 보고 판단하는 데 익숙 |
| 사용 맥락 | 주로 밤에 모바일로, 관측 나가기 전 날짜를 고를 때 |
| 우선순위 | 유일 페르소나 (최우선) |

## 페르소나 관계·우선순위

- 단일 페르소나. 관리자/게스트/다중 역할 없음(계정·로그인 범위 제외, intent-statement.md).
- 친구들도 같은 "취미 관측자" 특성으로 묶어 다룬다(입문자 전용 흐름은 첫 버전 제외).
