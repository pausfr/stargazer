# User Stories — 별 보기 좋은 날 추천 앱

> 근거: requirements.md(FR1~FR6, NFR1~NFR7), personas.md. US/AC ID는 영구 추적 키. 수용 기준은 Given/When/Then.

## 그룹 1: 연휴·주말 목록 보기

### US1.1 다가오는 연휴·주말 목록 보기 (Must) — FR1.1, FR1.4
As a 취미 관측자, I want 다가오는 3개월 이상의 주말·공휴일 연휴를 날짜순 카드 목록으로 보기, so that 언제 별 보러 갈지 후보를 한눈에 훑을 수 있다.
- AC1.1.1 Given 앱을 연다 When 메인 화면이 로드된다 Then 현재 시점부터 3개월 이상 앞의 주말·공휴일 연휴가 날짜순 카드로 표시된다.
- AC1.1.2 Given 메인 목록이 표시된다 When 특정 연휴 카드를 본다 Then "그날 밤"은 KST 기준 해당 날짜 저녁~다음날 새벽으로 묶여 있다.
- AC1.1.3 Given 데이터 로딩 중이다 When 아직 목록이 준비되지 않았다 Then 카드 자리에 로딩(스켈레톤) 상태가 표시된다.

### US1.2 공휴일 연휴가 없을 때 주말 표시 (Should) — FR1.2
As a 취미 관측자, I want 향후 3개월에 공휴일 연휴가 없어도 주말이라도 목록에 보기, so that 목록이 비어 막막해지지 않는다.
- AC1.2.1 Given 향후 3개월에 공휴일 연휴가 없다 When 메인 목록을 연다 Then 주말만이라도 카드로 표시된다.
- AC1.2.2 Given 표시할 주말·연휴가 전혀 없다(드묾) When 메인을 연다 Then "표시할 날짜가 없어요" 안내가 보인다.

### US1.3 카드 요약 정보 보기 (Must) — FR1.3
As a 취미 관측자, I want 각 카드에서 날짜·연휴명·달 위상·조도와 (예보 있는 날이면) 구름 요약을 보기, so that 상세로 들어가기 전에 후보를 가늠한다.
- AC1.3.1 Given 메인 목록의 카드를 본다 When 카드가 렌더링된다 Then 날짜/연휴 이름, 달 위상 아이콘과 조도(%)가 표시된다.
- AC1.3.2 Given 구름 예보 데이터가 있는 날의 카드다 When 카드를 본다 Then 구름량 요약이 함께 표시된다.
- AC1.3.3 Given 구름 예보 데이터가 없는 먼 날짜의 카드다 When 카드를 본다 Then 구름 자리에 "날씨는 날짜가 가까워지면 표시"로 구분된다.

## 그룹 2: 추천(관측 좋은 날) 강조

### US2.1 추천 날 강조 보기 (Must) — FR2.1, FR2.2, FR2.3, FR2.4
As a 취미 관측자, I want 관측 좋은 밤을 카드에서 눈에 띄게 강조해 보기, so that 좋은 후보를 빠르게 찾는다.
- AC2.1.1 Given 구름 예보가 있는 날의 달 조도 ≤ 20%이고 구름량 ≤ 30%다 When 메인 목록을 본다 Then 그 카드는 노란 테두리 + 별 아이콘 + "추천" 라벨로 강조된다.
- AC2.1.2 Given 달 조도 ≤ 20%이지만 구름량 > 30%인 가까운 날이다 When 메인 목록을 본다 Then 그 카드는 추천으로 강조되지 않는다.
- AC2.1.3 Given 구름 예보가 없는 먼 날짜의 달 조도 ≤ 20%다 When 메인 목록을 본다 Then 달 조도만으로 추천 강조된다(구름 조건은 적용하지 않음).
- AC2.1.4 Given 추천 강조가 적용된다 When 강조를 표시한다 Then 색(노란 테두리)만이 아니라 아이콘·라벨로도 추천임이 전달된다.

## 그룹 3: 상세 그래프 보기

### US3.1 상세 그래프로 그날 밤 판단 (Must) — FR3.1, FR3.2, FR3.3, FR4.1, FR4.2
As a 취미 관측자, I want 카드를 눌러 그날 밤의 달 밝기·구름량·박명 그래프를 보기, so that 그 밤이 관측에 좋은지 판단한다.
- AC3.1.1 Given 메인에서 카드를 탭한다 When 상세 화면이 열린다 Then x축=시간, 좌y=달 밝기(조도 0~100%), 우y=구름량(%)이 겹쳐진 이중축 그래프가 표시된다.
- AC3.1.2 Given 상세 그래프가 표시된다 When 그래프를 본다 Then 박명 구간(시민/항해/천문)이 음영으로, "완전한 밤"(저녁 천문박명 종료~새벽 천문박명 시작) 구간이 구분되어 표시된다.
- AC3.1.3 Given 구름 예보가 없는 먼 날짜의 상세다 When 그래프를 본다 Then 구름량 곡선 없이 달 밝기·박명이 표시되고 "날씨는 날짜가 가까워지면" 안내가 보인다.

### US3.2 핵심 숫자 요약·범례 보기 (Must) — FR3.4, FR3.5
As a 취미 관측자, I want 완전한 밤 구간과 월출·월몰 시각을 숫자로, 그래프 요소를 범례로 보기, so that 그래프를 정확히 읽는다.
- AC3.2.1 Given 상세 화면이 열렸다 When 요약 영역을 본다 Then 완전한 밤 구간의 시작·끝 시각과 월출·월몰 시각이 숫자로 표시된다.
- AC3.2.2 Given 상세 그래프가 표시된다 When 범례를 본다 Then 달 밝기선·구름량선·박명 음영·완전한 밤의 의미가 설명된다.
- AC3.2.3 Given 그날 밤에 월출 또는 월몰이 일어나지 않는 경우(달이 밤새 떠 있거나 아예 뜨지 않음) When 요약을 본다 Then 해당 시각 자리에 "없음"(월출 없음/월몰 없음)으로 구분해 표시된다.

### US3.3 뒤로가기로 다른 날 비교 (Must) — FR3.6
As a 취미 관측자, I want 상세에서 뒤로가 다른 카드를 열어 비교하기, so that 여러 밤을 견줘 고른다.
- AC3.3.1 Given 상세 화면을 보고 있다 When 뒤로가기를 한다 Then 메인 목록의 이전 위치로 돌아간다.
- AC3.3.2 Given 상세 화면이다 When 화면을 본다 Then 이전/다음 연휴로 바로 넘기는 버튼은 없다(첫 버전 제외).

## 그룹 4: 데이터·오류 처리

### US4.1 날씨 실패 시 부분 표시 (Must) — FR5.1, FR5.2, FR5.3, FR6.1, FR6.3
As a 취미 관측자, I want 날씨를 못 받아와도 달·박명·월출몰은 그대로 보기, so that 날씨 문제로 전체가 막히지 않는다.
- AC4.1.1 Given 날씨 API 호출이 실패한다 When 메인/상세를 본다 Then 달·박명·월출몰은 표시되고 구름 부분만 "불러오기 실패"로 표시된다.
- AC4.1.2 Given 앱을 연다 When 데이터를 받아온다 Then 받아온 데이터는 짧게 캐시되어 과도한 재호출을 막는다.
- AC4.1.3 Given 각 화면이 로딩/성공/부분/에러 상태에 있다 When 화면을 본다 Then 상태가 구분되어 표시된다.

### US4.2 천문 계산 실패 시 에러·재시도 (Must) — FR6.2, FR6.3
As a 취미 관측자, I want 천문 계산이 실패하면 에러와 재시도 수단을 보기, so that 일시적 오류에서 회복한다.
- AC4.2.1 Given 천문 계산이 실패한다(드묾) When 해당 카드/상세를 본다 Then 에러 메시지와 재시도 수단이 표시된다.
- AC4.2.2 Given 재시도를 누른다 When 계산이 성공한다 Then 정상 데이터로 다시 표시된다.
