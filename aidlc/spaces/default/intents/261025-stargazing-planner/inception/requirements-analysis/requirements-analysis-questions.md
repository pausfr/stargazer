## Consolidated Summary Confirmation

- 추천 판정: 달 조도가 낮고(어두운 밤) + 가까운 날이면 구름도 적어야 "추천". 구름이 많으면 추천 강조를 뺀다(달·날씨 둘 다 좋아야 추천). 먼 날짜는 날씨 예보가 없으니 그 경우 달 조도만으로 판정.
- 빈/경계 처리: 공휴일 연휴 없으면 주말만이라도 표시 / 날씨 API 실패 시 구름만 "불러오기 실패", 나머지는 표시 / 천문 계산 실패 시 에러+재시도.
- 성능: 엄격한 수치 목표 없음(흔한 모바일 네트워크에서 몇 초 내).
