# Accessibility Checklist — 별 보기 좋은 날 추천 앱

> 목표 수준: 모바일·터치 위주의 기본 접근성(가벼운 개인 앱). WCAG AA 전면 준수는 목표로 두지 않되, 아래 핵심은 지킨다. 근거: refined-mockups 인터뷰 Q5, project.md/team.md.

## 색 비의존

- [ ] 추천 강조는 노란색만이 아니라 별 아이콘 + "추천" 텍스트로도 전달한다.
- [ ] 그래프의 달·구름 곡선은 색 + 선 모양(실선/점선) + 범례로 구분한다.
- [ ] 날씨·달 위상은 아이콘 + 텍스트 라벨을 함께 쓴다.

## 대비·가독

- [ ] 다크모드 본문 텍스트가 배경 대비 읽히는 수준을 확보한다(대비 점검).
- [ ] 작은 보조 텍스트(조도%, 시각)도 판독 가능한 크기·대비.

## 터치 (초점)

- [ ] 모든 탭 대상(카드 전체, 뒤로가기, 재시도 버튼)의 터치 타깃 ≥ 44x44px.
- [ ] 인접한 탭 대상 사이 충분한 간격으로 오탭 방지.
- [ ] 탭 시 즉각적 눌림 피드백(<300ms).
- [ ] 주요 동작(카드 열기, 뒤로가기, 재시도)은 터치만으로 완결된다.

## 비시각 보조 (가벼운 수준)

- [ ] 그래프는 핵심 숫자 요약(완전한 밤 구간, 월출·월몰)을 텍스트로도 제공해 그래프를 못 읽어도 핵심을 얻는다.
- [ ] 이미지/아이콘에 의미 있는 대체 텍스트(장식용은 비워 둠).
- [ ] 제목 계층(h1 메인, h2 상세)을 올바르게 사용.

## 목표에서 제외 (이번 버전)

- 키보드 전용 완전 조작, 스크린리더 전면 최적화, WCAG AA 전 항목 준수는 이번 범위 밖(모바일·터치 개인 앱). 필요 시 다음 버전에서 강화. [Q5]
