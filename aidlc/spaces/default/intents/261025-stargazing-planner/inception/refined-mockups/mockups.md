# Refined Mockups — 별 보기 좋은 날 추천 앱 (모바일, 다크모드)

> 러프 와이어프레임(ideation/rough-mockups)을 상세화. 모바일 세로 기준, 기본 다크모드. 근거: wireframes.md, user-flow.md, stories.md, requirements.md.

## 팔레트·토큰 방향

- 배경: 깊은 남색~검정(밤하늘 느낌), 저채도 텍스트/보더. [Q1]
- 강조색: 노란색 — 오직 "추천" 강조와 핵심 CTA에만 사용(의미 있는 강조에 한정). [Q1] [project.md]
- 그래프: 달 밝기선·구름량선은 색 + 선 모양(실선/점선)으로 구분. [Q2]

## 화면 2: 상세 — 선택한 날 그래프 (US3.1, US3.2, US3.3)

```
+--------------------------------+
| < 뒤로   10/3 개천절 연휴      |   헤더(h2) + 뒤로(터치)
+--------------------------------+
| 완전한 밤: 20:30 ~ 04:10       |   핵심 숫자 요약
| 월몰 22:10 · 월출 09:30        |
+--------------------------------+
|  달밝기%               구름%   |
| 100|                   |100   |
|    | --- 달(실선)             |
|  50| ......... 구름(점선)      |
|    |:::::박명 음영:::::        |
|   0|___________________| 0    |
|    18  21  00  03  06 (시)     |
|    [시민][항해][완전한 밤 ]    |
+--------------------------------+
| 범례: --- 달밝기  ... 구름     |
|       [음영] 박명  [진] 완전밤 |
+--------------------------------+
```

<!-- Text fallback: 상단에 뒤로가기(터치)와 날짜 제목. 완전한 밤 구간과 월출·월몰 시각을 숫자로 요약. 이중축 그래프에서 달 밝기는 실선, 구름량은 점선으로 겹쳐 표시하고 박명 구간은 음영, 완전한 밤은 진한 음영. 아래 범례로 각 요소 설명. 상세 화면에는 추천 배지를 표시하지 않는다. -->

- 상세에는 "추천" 배지를 표시하지 않는다(메인에서만 강조). [Q3]
- 월출 또는 월몰이 그날 밤에 없으면 요약에서 "없음"으로 구분 표시. (US3.2 AC3.2.3)
- 먼 날짜는 구름 곡선 없이 "날씨는 날짜가 가까워지면" 안내. [requirements FR5.2]
