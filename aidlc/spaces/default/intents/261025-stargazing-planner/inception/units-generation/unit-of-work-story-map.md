## 설명 (어느 단위가 무엇을 맡나)

- **US1.1 / US1.2 (연휴·주말 목록, 빈 목록 처리)**: U3이 3개월+ 날짜·주말/연휴 산출과 KST 밤 범위를, U4가 카드 목록·로딩/빈 상태 렌더링을 맡는다.
- **US1.3 (카드 요약)**: U1(달 위상·조도), U2(구름 요약/없음 구분), U4(카드 표시).
- **US2.1 (추천 강조)**: U1(조도), U2(구름량), U3(추천 판정 규칙·임계값), U4(노란 테두리+아이콘+라벨, 색 비의존 강조).
- **US3.1 (상세 이중축 그래프)**: U1(달 밝기·박명), U2(구름량 곡선/없음 안내), U4(이중축 그래프·박명 음영·완전한 밤 렌더링).
- **US3.2 (핵심 숫자 요약·범례)**: U1(완전한 밤 구간·월출·월몰, "없음" 포함), U4(요약·범례 표시).
- **US3.3 (뒤로가기 비교)**: U4(네비게이션, 이전/다음 바로 이동 없음) — UI 전용.
- **US4.1 (날씨 실패 시 부분 표시)**: U2(실패/없음 구분 반환·캐시), U4(부분 상태 표시).
- **US4.2 (천문 계산 실패 에러·재시도)**: U1(계산 실패 신호), U4(에러 메시지·재시도 수단).

## 크로스커팅 (여러 단위에 걸친 관심사)

- **상태 구분(로딩/성공/부분/에러)** — US1.1, US4.1에 걸쳐 U4가 표시하되 U2의 상태 반환(없음/실패)과 U1의 실패 신호에 의존.
- **추천 판정** — US2.1은 U1·U2·U3·U4 네 단위 모두가 관여하는 대표적 크로스커팅.
- **"그날 밤" KST 범위** — U3이 산출하고 U1의 계산과 U4의 표시가 공유.

## 단위 내 구현 순서(단위별 참고)

각 단위 안에서의 작업 순서는 아래가 자연스럽다(단위 간 빌드 순서는 Delivery Planning이 DAG로 결정):
- U1: 달 조도 → 박명/완전한 밤 → 월출·월몰
- U2: API 어댑터(조회·없음/실패 구분) → 캐시
- U3: 달력(주말·연휴 산출) → 추천 판정 규칙
- U4: 메인 목록(카드·상태·추천 강조) → 상세 그래프(이중축·요약·범례) → 뒤로가기 네비
