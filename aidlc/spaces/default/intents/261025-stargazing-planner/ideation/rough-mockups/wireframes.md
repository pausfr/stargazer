## 화면 1: 메인 — 연휴/주말 카드 목록

각 카드는 하나의 주말 또는 공휴일 연휴. 달 위상이 좋은(어두운 밤) 추천 날은 **노란 테두리 + 별 아이콘 + "추천" 라벨**로 강조한다(색만으로 전달하지 않음). [Q2] [Q6]

```
+------------------------------+
| 별 보기 좋은 날   (다크모드) |   <- 헤더(h1), 앱 제목
+------------------------------+
| 다가오는 3개월               |   <- 섹션 라벨
|                              |
| +==========================+ |   <- 노란 테두리(추천)
| | * 추천                   | |   추천 배지(별 아이콘 + 라벨)
| | 10/3 (금) 개천절 연휴    | |   날짜 / 연휴명
| | () 그믐 근접  조도 8%    | |   달 위상 아이콘 + 조도%
| | 맑음 (가까운 날)         | |   구름량 요약(가까운 날만)
| +==========================+ |
|                              |
| +--------------------------+ |   <- 일반 카드(테두리 보통)
| | 10/11 (토) 주말          | |
| | (O) 상현  조도 55%       | |
| | 흐림 (가까운 날)         | |
| +--------------------------+ |
|                              |
| +--------------------------+ |
| | 12/25 (목) 성탄 연휴     | |
| | () 하현  조도 40%        | |
| | 날씨: 날짜 가까워지면    | |   먼 날 = 날씨 미표시(구분)
| +--------------------------+ |
|                              |
|            ...               |
+------------------------------+
```

**화면 상태**
- 로딩: 카드 자리 스켈레톤(펄스).
- 성공(위 그림): 카드 목록 표시.
- 비어 있음: "표시할 연휴가 없어요" (3개월 내 없을 때 — 드묾) + 안내.
- 에러: "날짜/천문 데이터를 불러오지 못했어요. 다시 시도" + 재시도 버튼. (구름량만 실패하면 카드는 뜨되 날씨 자리에 "날씨 불러오기 실패" 표시 — 부분 상태)
- 부분: 가까운 날은 구름량 있음 / 먼 날은 달·박명만. 카드에 명확히 구분.

**접근성 메모**: 헤더 h1="별 보기 좋은 날", 랜드마크 header/main. 각 카드는 버튼/링크로 키보드 포커스 가능, Enter로 상세 진입. 추천 강조는 노란색 + 별 아이콘 + "추천" 텍스트(색 비의존). 기본 수준 목표 — 색 비의존 + 읽히는 대비(가벼운 개인 앱 수준, Q6=A). [Q6]

## 화면 2: 상세 — 선택한 날의 그래프

```
+------------------------------+
| < 뒤로   10/3 개천절 연휴    |   <- 헤더(h2) + 뒤로가기
+------------------------------+
| 완전한 밤: 20:30 ~ 04:10       |   <- 핵심 숫자 요약(저녁 천문박명 끝 ~ 새벽 천문박명 시작)
| 월몰 22:10 · 월출 09:30      |   <- 월출/월몰
+------------------------------+
| [ 그래프 ]                   |
|  달밝기%                구름%|   <- 좌축 / 우축 라벨
| 100|                    |100 |
|    |  ___               |    |
|    | /   \   (구름)     |    |
|  50|/     \__   .....   | 50 |
|    |:::::::::::\:::......|    |   ::: = 박명 음영
|   0|___________\________| 0  |
|    18  21  00  03  06 (시)   |   <- x=시간축
|    [시민][항해][  완전한 밤 ]|   <- 박명 구간 띠 + 완전한 밤
|    (해질녘 ->)   [천문박명끝]|      완전한 밤 = 천문박명끝~새벽천문박명시작
+------------------------------+
| 범례                         |
|  --- 달 밝기(조도)           |
|  ... 구름량                  |
|  [음영] 박명(시민/항해/천문) |
|  [진한 음영] 완전한 밤       |
+------------------------------+
```

**화면 상태**
- 로딩: 그래프 영역 스켈레톤 + 숫자 요약 자리 표시.
- 성공(위 그림): 그래프·요약·범례 표시.
- 비어 있음: 해당 없음(날이 선택되면 항상 천문 데이터는 있음).
- 에러: 천문 계산 실패 시 "그래프를 그릴 수 없어요 + 재시도". 구름량만 실패면 구름 곡선 자리에 "구름량 없음"으로 그래프는 유지(부분).
- 부분: 먼 날짜 = 구름량 곡선 없이 달 밝기·박명·월출월몰만, "날씨는 날짜가 가까워지면" 안내.

**접근성 메모**: 제목 h2, 뒤로가기 키보드 포커스 가능. 그래프는 대체 텍스트/요약(핵심 숫자)으로 비시각 사용자도 핵심 파악 가능. 선 구분은 색 + 선 모양(실선/점선) + 범례 텍스트로(색 비의존). 박명 띠는 음영 + 텍스트 라벨. [Q3] [Q6]

## 정보 구조 (IA)

- 메인(목록, h1) → 상세(그래프, h2). 2단계 평면 구조, 뒤로가기로 복귀. 이전/다음 연휴 바로 이동은 MVP 제외. [Q1] [Q3] [Q4]

## Assumptions & Open Questions

- "완전한 밤"은 **저녁 천문박명 종료 ~ 새벽 천문박명 시작** 사이의 한 구간으로 정의한다. 요약 숫자와 그래프 박명 띠의 "완전한 밤"은 같은 구간을 가리킨다.
- 그래프의 정확한 축 스케일·색/선 스타일·반응형 세부는 Refined Mockups/설계에서 구체화한다. [assumption]
- "추천" 판정 기준(달 위상 임계값)은 설계/구현에서 수치화한다. [assumption]
- 메인에서 추천으로 강조된 날을 상세로 들어왔을 때 상세에도 추천 배지를 노출할지는 Refined Mockups에서 정한다. [assumption]
