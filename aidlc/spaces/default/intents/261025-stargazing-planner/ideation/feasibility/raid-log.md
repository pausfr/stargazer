# RAID Log — 별 보기 좋은 날 추천 앱

> RAID = Risks(위험), Assumptions(가정), Issues(현안), Dependencies(의존). 개인 프로젝트 규모에 맞춰 핵심만 기록한다.

| ID | 위험 | 영향 | 가능성 | 완화 |
|----|------|------|--------|------|
| R-1 | 무료 날씨 API의 한국 운량 예보 품질이 기대에 못 미침 | 중 | 중 | 설계 시 1~2개 API 비교 검증, 운량 필드 제공·정확도 확인 [Q1] [assumption] |
