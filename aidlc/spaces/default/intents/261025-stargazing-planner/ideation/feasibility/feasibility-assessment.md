# Feasibility Assessment — 별 보기 좋은 날 추천 앱

> 근거: intent-statement.md(핵심 가치·범위), build-vs-buy.md(데이터 확보 방향), market-trends.md(무료 데이터 환경), 그리고 이 단계 질문 답변.

## 요약 판정

전체적으로 **실현 가능(feasible)** 하다. 핵심 데이터(달 위상·박명)는 결정론적으로 계산 가능하고, 구름량은 무료 날씨 API로 받을 수 있으며, 소수 사용자용 모바일 웹앱은 무료 정적 호스팅으로 충분하다. [Q3] 가장 주의할 지점은 "먼 날짜의 날씨 예보 부재"이며, 이는 표시 방식으로 해소하기로 했다. [Q1]

## 핵심 설계 전제 (실현 가능성을 좌우)

- **예보 지평 분리 표시**: 가까운 날짜는 구름량까지, 먼 날짜(3개월 범위)는 달 위상·박명만 확정으로 보여주고 날씨는 날짜가 가까워지면 채운다. 이 전제가 "3개월 비교"와 "무료 API 예보 한계"를 양립시킨다. [Q1]
- **클라이언트 중심 구조**: 천문 계산을 앱(브라우저)에서 직접 수행하면 서버가 필요 없어 무료 정적 호스팅이 성립한다. [Q2] [Q3]

## Assumptions & Open Questions

- 선택할 무료 날씨 API의 실제 한국 운량 예보 품질·무료 한도는 설계/구현 단계에서 검증한다. [assumption]
- 한국 ~5개 지역 구획의 경계·대표 좌표는 아직 미정이다. [assumption]
- 한국 공휴일 데이터의 출처(규칙 계산 vs 공개 데이터)는 설계 단계에서 정한다. [assumption]
